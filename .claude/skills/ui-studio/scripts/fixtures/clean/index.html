Field notes

Three readings that disagreed with the model

The ridge dries from the top down, not the bottom up, in every year we have data for. The model had it the other way, which is why the 2019 forecast was eleven days early.

  • Snowmelt, plot 04-A11 days early

Method

A thermometer and a notebook

The instrument has not changed on purpose. A consistent imperfect reading beats an inconsistent precise one across a fifty-year series, so the notebooks are transcribed rather than replaced.
